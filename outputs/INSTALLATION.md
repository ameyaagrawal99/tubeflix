# Install TubeFlix in Chrome

1. Unzip the TubeFlix extension archive.
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode** in the top-right corner.
4. Click **Load unpacked**.
5. Select the unzipped TubeFlix extension folder.
6. Open or refresh `https://www.youtube.com/`.

Pin **TubeFlix** from Chrome's extensions menu to access:

- Cinematic experience on/off
- Hover-detail cards
- Reduced motion
- Compact six-card rails
- Restore native YouTube

TubeFlix intentionally uses static hover previews instead of embedded autoplay. Some creators block third-party embedding, which otherwise produces YouTube's “Video unavailable” overlay. Play always opens YouTube's native watch page.

The extension uses only the `storage` permission and access to `www.youtube.com`. It has no backend, analytics, or external recommendation system.
